### [1] [IndoorBEV: A Lightweight Real-Time LiDAR BEV Perception System for Indoor Mobile Robots](https://arxiv.org/abs/2610.00355)
*Haichuan Li*

Main category: cs.RO

TL;DR: IndoorBEV是一个轻量级LiDAR感知框架，仅0.6M参数，通过高度感知的鸟瞰图表示解决室内三维环境垂直几何信息丢失问题，实现169.6ms平均延迟（200ms期限）和极低的内存消耗。

Motivation: 移动机器人需要在严格的时间和资源约束下理解复杂的三维室内感知环境。现有方法的痛点在于：基于点的/体素的方法计算开销大；传统BEV表示在提升效率时会丢弃垂直几何信息，造成精度与效率的权衡困境。

Method: 高度感知的鸟瞰图(Height-aware BEV) representations + 统计特征编码（多频高度编码）+ 2D卷积高效处理三维线索；轻量编码器融合互补几何特征、多尺度局部表示和紧凑全局场景上下文；解耦的密集预测头同时输出语义BEV地图和定向物体边界框。

Result: 0.6M参数，模型存储2.3MB；NVIDIA AGX Orin上GPU内存仅21.52MB/次推理，平均延迟169.6ms（满足200ms期限），超期率仅1.8%。在仿真场景、真实机器人扫描和公开室内点云数据集上验证了精度与资源效率的优越权衡。

Conclusion: 显式编码垂直几何信息的紧凑BEV表示框架是实现资源高效室内LiDAR感知的有效方案，证明了该方法在延迟敏感、内存受限环境下平衡感知精度和资源开销的可实现性。

Abstract: Efficient indoor LiDAR perception is challenging because mobile robots must understand cluttered three-dimensional environments under strict latency and memory constraints. Existing point-based and voxel-based methods often incur substantial computational overhead, whereas conventional bird's-eye-view (BEV) representations improve efficiency at the cost of discarding vertical geometric information. We present IndoorBEV, a lightweight LiDAR perception framework that mitigates this tradeoff through a height-aware BEV representation and geometry-conditioned feature fusion. IndoorBEV summarizes the vertical point distribution in each BEV cell using statistical height features and multi-frequency height encoding, allowing informative three-dimensional cues to be processed efficiently by two-dimensional convolutions. A lightweight encoder then integrates complementary geometric features with multi-scale local representations and compact global scene context. Decoupled dense prediction heads jointly produce semantic BEV maps and oriented object bounding boxes. IndoorBEV contains only 0.6M parameters and requires 2.3 MB of model storage. On an NVIDIA AGX Orin, it uses 21.52 MB of GPU memory per inference and achieves a mean latency of 169.6 ms under a 200 ms perception deadline, with a deadline miss ratio of 1.8\%. Evaluations on simulated scenes, real-world robot scans, and an open-source indoor point-cloud dataset demonstrate a favorable tradeoff among perception accuracy, latency, and memory consumption. These results indicate that explicitly encoding vertical geometry within a compact BEV representation provides an effective approach to resource-efficient indoor LiDAR perception.
